A port of the classic action-adventure game **Oni** to ARM Linux (armhf) using SDL2, enabling it to run on handheld gaming devices via [PortMaster](https://portmaster.games/).

## Notes

A retail copy of the game (specifically the GameDataFolder from the Windows edition) is needed to play.

Community modifications (like [Anniversary Edition](https://wiki.oni2.net/Anniversary_Edition)) have not been thoroughly tested with the Portmaster build and are not guaranteed to work properly.

This port is possible thanks to the efforts of the following:

* The [Internet Archive](https://archive.org/details/oni-source) for hosing the source
* [Mark Sowden](https://github.com/hogsy/) for their work on the template generation paths for initial compilation 
* The Oni community at [OniGalore](https://wiki.oni2.net/OniGalore:About) for providing valuable insight into structure definitions and layout
* Bungie West and Rockstar Games for development and publication

|L1|Pick up Weapon|
|L2|Diary|
